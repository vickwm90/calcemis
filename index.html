Factor de conversión de miligramos por litro (mg/l) a Megagramos por metro cúbico (Mg/m³): 1 mg/l = 1 Mg/m³

  • a) Miligramos a Megagramos: 1 Mg = 10^9 mg -> un Megagramo equivale a un millón de gramos y un gramo a mil miligramos
  • b) Litros a Metros cúbicos: 1 m³ = 1,000 litros
  • c) Relación final: proporción de masa entre volumen ( (106 mg) / (1 L) ) = 1 Mg/m³ → ( (1 mg ) / (1 L) ) = (1/10m³) * ( mg / L )
  • d) (1/10³) * ( mg / L ) × ( (1 Mg) / (1,000,000 g) ) × ( (1,000 L) / (1 m³) ) = 10-6 Mg/m³ = 1 g/m³ = 10-6 ton/m³
